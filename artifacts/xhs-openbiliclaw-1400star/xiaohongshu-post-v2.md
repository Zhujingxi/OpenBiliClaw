# 发布标题

越刷越无聊？我手搓了个自己的推荐系统

# 正文

最开始做这个项目，是因为我连着看了两天军事科普。

然后接下来很长一段时间，首页都是“XX 局势突变”“XX 又出大事”。偶尔刷到一条特别合胃口的，想再看点类似但不重复的，反而找不到了。

我当时就在想：平台其实很清楚我点了什么、停留了多久，但它不知道我为什么点。

看做饭视频，不一定是想学做菜，也可能只是下班后想看点治愈的；看旅行 vlog，也不一定真要出去玩，可能只是喜欢那种“在别处”的感觉。

所以我自己写了 OpenBiliClaw。

它做的事情其实不复杂：

把你自己选择接入的浏览、收藏、关注、喜欢和不感兴趣这些信息留在本机，慢慢整理成一份个人画像。然后 Agent 再带着这份画像，去 B站、小红书、抖音、YouTube 等平台找内容。

推荐结果会直接写为什么觉得你可能会喜欢。点喜欢、不感兴趣、收藏，或者跟它聊两句，都会影响下一轮推荐。对以前没接触过的方向，它也会先小范围试探；猜错了，就少推或者不再探索这个方向。

目前推荐流、个人画像、兴趣试探、推荐理由这些都已经能用了。来源可以自己开关，PC、手机和浏览器插件都能看。

项目做了三个月，GitHub 从 0 到了 1400+ Stars，我也还在继续更新。

如果你也受够了平台的“猜你喜欢”，或者对“属于自己的推荐系统”这个思路感兴趣，可以去 GitHub 搜：

OpenBiliClaw

项目完全开源。觉得有点意思的话，帮我点个 Star；有问题也可以直接提 Issue。

也想问问大家：你最想先换掉哪个平台的推荐流？
